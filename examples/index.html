The problem

Most highlight libraries wrap every match in a <mark> or <span>. That splits text nodes, breaks event listeners, confuses React and other frameworks during reconciliation, corrupts contenteditable selections, and can shift layout. Undoing it means walking the DOM again and hoping nothing else changed.

The solution

The CSS Custom Highlight API lets a page register a set of Range objects under a name and style them with ::highlight(name). The browser paints the colour directly on the text. Nothing is inserted, so the document tree stays exactly as you wrote it. This library finds matches, builds the ranges, and keeps them in sync for you.

What you get

Groups with their own colour and priority, matches that cross element boundaries like custom highlight, accent-insensitive search so cafe finds café and résumé, find-in-page navigation with a live count, hover and click callbacks for tooltips, and a strict mode that never touches the DOM even on old browsers. Released in 2026, version 0.2.0 supports Chrome 105, Safari 17.2, and Firefox 140 or newer.

Glossary

A Range is a start and end point in the document. A Highlight is a set of ranges painted together. The registry is the map at CSS.highlights where each highlight is stored by name.
